# Oak: French vs American

| Trait        | French Oak                                        | American Oak                                      |
| ------------ | ------------------------------------------------- | ------------------------------------------------- |
| Species      | Quercus petraea / robur                           | Quercus alba                                      |
| Grain        | Tight                                             | Loose                                             |
| Flavor       | Subtle, savory spice, toast                       | Bold, sweet, coconut, dill                        |
| Vanilla      | Less, integrated                                  | More, pronounced                                  |
| Tannins      | Silky, structural                                 | Softer, rounder                                   |
| Cost         | Expensive                                         | Cheap                                             |
| Typical use  | Burgundy, Bordeaux, premium Pinot/Chardonnay      | Rioja, Zinfandel, budget-friendly reds            |
| Integrates   | Slowly, ages well                                 | Quickly, shows early                              |

> Newer barrels impart more oak flavor (toast, vanilla, spice) than older, neutral barrels — each reuse strips out more of the oak character.

## Toast Level Spectrum

`espresso ← more toast | spices | vanilla → less toast`

| Toast level | Flavor character            |
| ----------- | --------------------------- |
| Heavy       | espresso, coffee, smoke, char |
| Medium      | baking spices, clove, cinnamon |
| Light       | vanilla, coconut, sweet     |
